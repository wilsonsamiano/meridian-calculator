# Contributing to Meridian

Bug reports, math-engine fixes, and accessibility patches are welcome.

1. Fork [wilsonsamiano/meridian-calculator](https://github.com/wilsonsamiano/meridian-calculator)
2. Create a branch
3. Keep the calculator fully client-side (no accounts, no network required after first load)
4. Open a pull request

By contributing you agree your work is licensed under the MIT License.
